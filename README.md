# Testing-Machine

# MESIN TEST BENDING ANTENNA

TATA CARA PENGGUNAAN MESIN TEST BENDING ANTENNA

1.	Colokkan kabel power terlebih dahulu.
2.	Pastikan antena berada pada sudut 0° sebelum menyalakan mesin/dinamo OFF.
3.	Atur sudut pengujian 180° atau 360° sesuai dengan jig dan jenis antenna, kemudian nyalakan mesin/dinamo ON.
4.	Atur Cycle Per Minute (CPM).
5.	Atur waktu pengujian sesuai kebutuhan.
6.	Setelah semua pengaturan selesai, tekan OK untuk memulai pengujian.
7.	Untuk RESET, tekan dan tahan tombol OK selama 3–5 detik.

PERHATIAN:
•	Selalu pastikan antena berada pada posisi sudut 0° sebelum mesin dinyalakan dan sebelum pengujian dimulai kembali untuk mencegah kesalahan posisi dan kerusakan pada jig/antena.
•	JAUHKAN BENDA APA PUN SAAT MESIN BEROPERASI!!!

# MESIN TEST EXTEND & RETRACT ANTENNA DAN MESIN TEST PRINTING BOX

TATA CARA PENGGUNAAN 
MESIN TEST EXTEND & RETRACT ANTENNA
DAN MESIN TEST PRINTING BOX

1.	Colokkan kabel power terlebih dahulu.
2.	Pastikan antena berada di titik ZERO sebelum menyalakan mesin/dinamo OFF.
3.	Atur Length Max Antena sesuai kebutuhan dan nyalakan mesin/dinamo ON.
4.	Atur Cycle Per Minute (CPM).
5.	Atur waktu pengujian sesuai kebutuhan.
6.	Tekan OK untuk memulai pengujian.
7.	Jika terjadi kesalahan pengaturan, tekan RESET dan lakukan pengaturan kembali.

PERHATIAN:
•	Selalu pastikan antena berada pada posisi ZERO sebelum mesin dinyalakan dan sebelum pengujian dimulai kembali untuk mencegah kesalahan posisi dan kerusakan pada jig/antena.
•	JAUHKAN BENDA APA PUN SAAT MESIN BEROPERASI!!!
